Patched build — image preview fix

Version 1.6.2 · fixes broken reference-image previews

⚠️

Google Flow made a small change to how reference-image previews load. Because of it, reference thumbnails in the Library and on your job rows can appear blank or broken in the current version. This patched build fixes it — generation itself was never affected.

Download the fix

This is the same extension with the preview fix applied. It keeps the same extension ID, so your sign-in and license carry over — nothing to re-activate.

Download v1.6.2 (.zip)
~330 KB · Chrome / Edge · unzip before installing

Install it (2 minutes)

  1. Unzip the downloaded file. You'll get a folder named TryAIToday-Flow-Automator.
  2. Open chrome://extensions in your browser.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked and select the unzipped TryAIToday-Flow-Automator folder.
  5. Open the side panel — it now runs v1.6.2 with previews working. You can remove the old Web Store copy if you like; your account stays signed in.

Tip: keep the unzipped folder somewhere safe — deleting it removes the extension.

Prefer to wait for the Web Store update?

That's fine — the same fix is being submitted to the Chrome Web Store and will arrive automatically once Google approves it. This build just lets you get it today.

You can reopen this message inside the extension anytime from Settings → “Clear cache & fix broken actions.”
